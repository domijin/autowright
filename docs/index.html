How it works
1 · Say it

Describe the job like you'd tell a person.

No code, no settings maze. "Check the manga I follow for new chapters every morning at 8" is a complete instruction.

2 · Read it

Your AI writes it as short, readable steps.

Plain Python you can actually open and understand. Ask for changes in chat until it's right.

3 · Let it run

Autowright executes it on schedule, forever.

The same exact scripts every time: no re-prompting, no drift. It runs even with the window closed.

Your automations execute only on this Mac

No cloud runners, no subscriptions. Close the window and the schedule still fires, locally.

Nothing executes until you approve it

Every script is human-readable, and creating or saving an automation is always your click, never the AI's.

Passwords never leave your Keychain

Secrets stay in the macOS Keychain and are injected only at runtime, never in a script or a log.

Under the hood

Triggers that listen

On a schedule, once, on app start, or when a Discord or iMessage message arrives.

Runs with the window closed

A local scheduler keeps firing, and the menu bar shows what ran, with a red dot when something needs you.

Every edit is a version

Approved changes become v2, v3… Test a draft in isolation, roll back any time.

Memory between runs

Automations remember what they've already seen, with automatic snapshots and one-click restore.

Watch it work

Per-step status, streamed logs, and a full execution history across every automation.

Share it as a file

Export any automation as a portable .autowright file. Secret values and memory never leave this Mac.
